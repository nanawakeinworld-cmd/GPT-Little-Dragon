# 常见问题排查 · Troubleshooting

## 快速对照表

| 现象 | 最可能的原因 | 处理 |
|---|---|---|
| 主题导入了，但指针没变 | 没有点 Apply；系统指针颜色被改过 | 点 Apply；重置指针颜色 |
| 只有部分窗口生效 | 系统指针颜色未重置 | 辅助功能 → 显示 → 重置颜色 |
| 重启后恢复默认 | 没装 Helper Tool | MaCursor 设置里安装 Helper |
| 切换用户后恢复默认 | Helper 未运行 | 重新登录，检查登录项 |
| 终端 / Adobe / 游戏里无效 | 应用自绘光标 | 无法修复，属系统限制 |
| 指针边缘模糊 | 只用了 1× 图 | 确认主题含 2×；MaCursor 里检查 HiDPI |
| 指针太大 / 太小 | 缩放比例不合适 | 用 MaCursor 的缩放滑块 |
| 动画不播放 | 当前光标角色没有动画 | 只有 Wait / 忙碌角色有动画 |
| 导入失败 / 文件损坏 | 下载不完整或系统过旧 | 重新下载；确认 macOS 13+ |
| 应用提示“无法验证开发者” | 系统安全策略 | 系统设置 → 隐私与安全性 → 仍要打开 |

## 1. 指针完全没变化

按顺序检查：

1. 主题是否真的应用了？MaCursor 里选中的是不是「GPT 小龙 v16」，有没有点 **Apply**。
2. 系统指针颜色是否被改过？
   `系统设置 → 辅助功能 → 显示 → 指针颜色 → 重置颜色`。
3. 当前应用是否自绘光标？换到 Finder 桌面再试。
4. 注销并重新登录。

## 2. 只有部分地方生效

这是最典型的情况，通常就是**指针颜色没重置**。

macOS 会把“指针颜色”作为一种辅助功能覆盖层；它开着的时候，自定义指针只在部分
窗口生效。重置颜色后一般就正常了。

## 3. 重启或切换用户后还原

装 MaCursor 的 Helper Tool：

`MaCursor → Settings → General → Helper Tool → Install`

然后确认 `系统设置 → 通用 → 登录项` 里有 MaCursorHelper。

## 4. 指针模糊

- 确认使用的是仓库里的 `v16` 主题文件，而不是自己转换的旧版本。
- 主题已经包含 1× / 2× 两套表示；如果仍然模糊，检查 MaCursor 的显示缩放设置。
- 非 Retina 外接屏上，80–92 pt 的角色指针本身会比系统箭头大，这是设计取舍。

## 5. 动画不动

当前 `v16` 只有两个系统角色带动画：

- `com.apple.coregraphics.Wait`（忙碌等待，7 帧）
- `com.apple.cursor.4`（后台工作，8 帧）

普通箭头、文本、缩放等静态角色本来就不会动。待机动画尚未接入主题，
详见 README 的状态与路线图。

## 6. 导入失败

- 确认系统是 **macOS 13 Ventura 或更高**。
- 确认文件是 `GPT-Little-Dragon-v16.cursor`，大小约 1.7 MB。
- 重新下载，排除传输损坏。
- 用 MaCursor 的 `File → Import Theme…` 而不是双击。
- 仍然失败：在 MaCursor 里导出错误信息，开 issue。

## 7. 想临时回到默认指针

MaCursor 菜单 `File → Reset System Cursor`，立即恢复，不需要卸载。

## 8. 收集排查信息

开 issue 时请附上：

- macOS 版本（`  → 关于本机`）
- 芯片型号（Apple Silicon / Intel）
- MaCursor 版本
- 主题文件名与大小
- 复现步骤
- 截图或录屏（注意打码个人信息）
